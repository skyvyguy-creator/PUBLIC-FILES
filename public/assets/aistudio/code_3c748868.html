DEDIKASI PADA KETELITIAN ANALITIS, DEBAT DINAMIS, DAN ESTETIKA BERMAKNA

Halo, saya Skyvero Hidayatullah Pardi — biasa dipanggil Vero. Saya merupakan lulusan SMA (Juni 2026) asal Kabupaten Solok, Sumatera Barat, yang kini melanjutkan studi di jenjang S1 Teknik Informatika di Institut Teknologi PLN (ITPLN) di Jakarta Barat.

Di bidang teknologi, fokus utama saya mencakup logika komputasional, algoritma dasar, arsitektur perangkat lunak, serta implementasi sistem yang efisien. Ketertarikan saya pada presisi berpikir terasah melalui keaktifan di dunia debat parlementer, di mana saya terbiasa bertindak sebagai Pembicara Ketiga (Whip) — menyintesis argumen, merekonstruksi benturan logika (clash), dan membedah esensi masalah di bawah tekanan waktu.

Di luar perkuliahan dan coding, saya memperkaya perspektif melalui apresiasi mendalam terhadap narasi pop-culture Jepang seperti Tokusatsu (Kamen Rider & Super Sentai), sinematografi, animasi, serta presisi mekanika dan kalkulasi frame data pada game pertarungan kompetitif. Perpaduan antara struktur disiplin dan apresiasi visual ini membentuk cara kerja saya dalam berkarya maupun menyelesaikan masalah.
